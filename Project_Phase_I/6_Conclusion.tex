\chapter{Conclusion and Future Work}

\section{Conclusion}
This project proposes and implements a novel agentic AI framework for cloud architecture recommendations. The system is designed to address key gaps in existing tools by providing end-to-end, factually grounded, and comparative architectural solutions.

The framework builds on foundational research in Multi-Agent Systems \cite{sycara1998multiagent} and Retrieval-Augmented Generation \cite{lewis2020rag}. It introduces a self-correcting "Evaluator-Optimizer" workflow \cite{anthropic2024agents}, implemented as a multi-agent graph using LangGraph \cite{langgraph2024docs}, to ensure that recommendations are validated against official vendor documentation.

The Phase 1 prototype, as detailed in Chapter 4, successfully demonstrates the implementation of this core feedback loop. Preliminary results show the system's ability to iterate and refine a solution based on internal validation. This confirms the feasibility of the proposed architecture and provides a strong foundation for the comparative multi-cloud analysis planned in Phase 2.

\section{Limitations}
While the developed framework demonstrates a novel approach, it is important to acknowledge the limitations of the current prototype:
\begin{itemize}
    \item \textbf{Knowledge Base Dependency:} The system's accuracy is entirely dependent on the quality and coverage of services in the vector database. Outdated or missing documentation (e.g., from complex PDFs not parsed correctly) will lead to incorrect validation.
    \item \textbf{Lack of Real-time Data:} The framework does not have access to real-time, account-specific data such as instance pricing, regional service availability, or existing user resources.

    \item \textbf{Scope of Evaluation:} The prototype evaluation will be conducted using benchmark scenarios. A large-scale, real-world usability study is outside the scope of this M.Tech project.
\end{itemize}

\section{Future Work}
Based on the work completed and the identified limitations, the following steps are planned to complete and extend this project.

\subsection{Phase 1 Completion (Semester 5)}
The immediate next steps are to complete the foundational framework:
\begin{itemize}
    \item \textbf{Evaluation Module:} Conduct the thorough testing deferred during the preliminary phase and implement human expert analysis to validate architectural viability beyond textual similarity.
\end{itemize}

\subsection{Phase 2: System Expansion (Semester 6)}
The second phase of the project will focus on expanding the framework into a true multi-cloud comparison tool.
\begin{itemize}
    \item \textbf{Knowledge Base Expansion (Azure):} The vector database will be expanded to include the official documentation for Microsoft Azure.
    \item \textbf{Team Azure Agent Development:} A parallel set of "Team Azure" agents (Generators, Validators) will be implemented.
    \item \textbf{Debate Orchestration:} A structured, multi-turn debate mechanism will be designed to allow the "Team AWS" and "Team Azure" agents to propose, critique, and refine competing solutions side-by-side.
\end{itemize}
