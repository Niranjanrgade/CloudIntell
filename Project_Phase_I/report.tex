\begin{center}
{\Large{\bf{ABSTRACT}}}
\end{center}


This project is creating an agentic AI framework to generate, validate, and optimize multi-cloud architectures. This report covers the design and implementation of the core agent workflow and system architecture for the proposed framework.

The project proposes an agentic AI system designed to support solution architects. It introduces an Evaluator-Optimizer workflow, which validates and improves recommendations using Retrieval Augmented Generation (RAG) grounded in vendor documentation. The system is built as a multi-agent framework where specialist agents collaborate to decompose a user query, generate a draft architecture, validate it against technical documentation, and iterate until a reliable solution is achieved.

The core technologies involved are Large Language Models (LLMs), multi-agent frameworks (LangGraph), and vector database (Chroma). The project delivers a functional prototype that provides efficient, secure, and cost-optimized cloud solutions. Quantitative evaluation utilizing ROUGE-L, METEOR, and BERTScore metrics demonstrates the effectiveness of the Evaluator-Optimizer workflow in improving the semantic quality and factual grounding of the generated solutions through iterative validation.
