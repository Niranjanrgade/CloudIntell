\begin{center}
{\Large{\bf{ABSTRACT}}}
\end{center}


This project presents the complete design, implementation, and empirical evaluation of an agentic AI framework for cloud architecture generation and validation. Built as a direct extension of the Phase~1 prototype, this report documents the expansion from a single-provider AWS system to a fully operational multi-cloud platform supporting both Amazon Web Services and Microsoft Azure.

The central contribution is a four-stage pipeline orchestrated using LangGraph subgraphs: an architect phase that decomposes user requirements across computation, networking, storage, and database domains; a validator phase that fact-checks each domain's proposal against official vendor documentation retrieved through cross-encoder reranked ChromaDB vector stores; a conditional iteration loop that drives further refinement when validation identifies factual errors; and a final synthesis stage that compiles a deployable architectural document. The system additionally exposes a provider metadata registry enabling Infrastructure-as-Code generation hints for Terraform and native provider formats.

Evaluation was conducted across five real-world architectural scenarios using three frontier language model families---GPT-5.4, Claude Sonnet 4.6, and Gemini 3.1 Pro---under an LLM-as-a-Judge assessment framework scoring six dimensions aligned with the AWS Well-Architected Framework. Results establish that structured iterative validation produces a measurable quality gain over single-pass generation (judge total: 8.92 baseline to 9.25 with the full Evaluator-Optimizer loop). Claude Sonnet 4.6 achieved the highest aggregate judge score of 9.58 across scenarios, with GPT-5.4 and Gemini 3.1 Pro scoring 9.25 and 9.08 respectively; a methodological limitation concerning the use of Claude as both a generating and judging model is identified and discussed. An interactive Next.js user interface complements the backend, providing real-time workflow visualization, side-by-side provider comparison, and per-run model selection for both the reasoning and execution tiers.
